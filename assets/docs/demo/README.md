## 维护原则

同一个问题只允许一份活文档做主入口，其他文档最多引用，不重复承载当前答案。

1. 对外沟通只引用 `AI赋能演示定稿方案`，不要同时引用 v1、v2 和研发基准子文档。
2. 演示编排优先维护在 `演示路线与页面交互方案`，不要把点击路径散落到技术方案和开发指导。
3. 技术边界优先维护在 `技术实施定版方案`，不要把真实接口、真实模型训练或 HSE/供应链联动写成首版承诺。
4. 开发执行优先维护在 `开发指导`，不要把阶段任务写回对外定稿方案。
5. `../../v1/demo-研发基准/` 继续作为字段、对象、状态和素材抽取的细节来源；当前目录只维护开发前定稿口径。
6. 新增 demo 文档前先判断是否能并入当前四类职责，避免再次产生平行方案。
7. 移动、归档或重命名文档后，必须同步检查相对链接。
