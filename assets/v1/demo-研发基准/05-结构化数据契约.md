# 05. 结构化数据契约

> 本文负责：定义 demo 运行时读取的结构化数据对象、字段、状态、引用关系和 JSON 样例。  
> 本文不负责：素材原文解释；素材抽取见 [06-素材抽取与待补清单.md](06-素材抽取与待补清单.md)。  
> 关键口径：JSON 中的数据是 IMS 数据中台智能运维 demo 模块内的结构化演示数据，不是直接读取 Word、Excel、图片素材。

## 顶层集合

| 集合 | 单条对象含义 |
|---|---|
| `assets` | 一台泵机组 |
| `measurement_points` | 一个测点 |
| `threshold_rules` | 一套阈值规则 |
| `telemetry_series` | 一组时序运行数据 |
| `spectrum_features` | 一组频谱特征 |
| `phase_features` | 一组相位特征 |
| `warning_events` | 一次异常预警事件 |
| `diagnosis_runs` | 一次诊断模型运行结果 |
| `knowledge_items` | 一条知识库实体 |
| `knowledge_hits` | 一条知识命中结果 |
| `work_orders` | 一张 IMS 演示态处置票卡 |
| `field_feedback` | 一次现场反馈 |
| `reports` | 一份维修报告草稿 |
| `case_entries` | 一条知识库案例 |
| `reuse_scenarios` | 一次复用验证 |

## 来源标注

| 字段 | 含义 |
|---|---|
| `runtime_source` | demo 模块运行时数据域，例如 `IMS模块结构化数据`、`IMS模块监测数据回放`、`IMS模块知识库数据` |
| `basis_source` | 构造该字段的依据，例如 `P1检测报告抽取`、`P1作业卡抽取`、`历史报告抽取`、`演示构造`、`业务待补` |

规则：

```text
runtime_source 说明 demo 运行时从哪里读；
basis_source 说明这个 mock 字段是参考哪个业务素材抽取或构造的。
```

这些 `runtime_source` 都属于 IMS 数据中台智能运维 demo 模块内的数据域，不表示现场上传文件，也不表示绕开 IMS 的外部输入。

## 状态枚举

| 对象 | 状态字段 | 枚举 |
|---|---|---|
| `warning_events` | `status` | `new`、`diagnosed`、`confirmed`、`closed`、`case_reusable` |
| `warning_events` | `current_node` | `warning`、`diagnosis`、`review`、`knowledge`、`work_order`、`feedback`、`report`、`case_entry`、`reuse` |
| `work_orders` | `status` | `draft`、`assigned`、`executing`、`accepted`、`closed` |
| `reports` | `draft_status` | `draft`、`pending_confirm`、`confirmed`、`rejected` |
| `*.confirmation` | `status` | `pending_confirm`、`confirmed`、`rejected` |
| `knowledge_hits` | `status` | `hit`、`empty` |
