# 06. 素材抽取与待补清单

> 本文负责：说明业务提供的素材可以抽取出哪些结构化字段、指标、阈值、知识库内容和页面表达，并列出还需要业务补充确认的数据。  
> 本文不负责：定义 demo 运行流程。运行流程见 [01-业务流程闭环.md](01-业务流程闭环.md)。  
> 关键口径：素材不进入 demo 运行时；素材用于构造 IMS 数据中台智能运维 demo 模块内的结构化演示数据、诊断样例、知识库样例和页面表达。

## 素材定位

正确理解：

```text
业务素材
  -> 抽取结构化数据和业务规则
  -> 构造 IMS 智能运维 demo 模块的 JSON、图表、知识卡、作业卡、报告样例
  -> 运行时页面读取结构化演示数据
```

错误理解：

```text
业务素材
  -> demo 现场上传 / 导入
  -> 模型直接读取 Word / Excel / 图片
```

## 素材分区

| 目录 | 性质 | 使用方式 |
|---|---|---|
| `P1/` | P1 检测报告和对中作业卡 | 抽取 P1 不对中样例数据、作业步骤、知识库内容 |
| `notes/` | 业务方原始资料 | 抽取业务口径、IMS 字段、维护保养结构、报告模板 |
| `pic/` | 业务流程图、截图、参赛材料 | 抽取流程节点、页面参考、参赛表达方式 |
| `docs/`、`dfaft/` | 讨论草稿 | 只吸收讨论结论，不作为运行时数据源 |
| `v1/` | demo 研发基准 | 当前唯一执行口径 |

## 已能构造的 demo 数据

| 数据 / 表达 | 当前是否可构造 | 说明 |

| P1 不对中诊断样例 | 可以 | 基于 P1 检测报告抽取和演示构造 |
| IMS 设备台账 / 一泵一档 | 基本可以 | 设备基础信息已有，IMS 单元模型可补结构 |
| 测点和测点图 | 基本可以 | P1 报告可抽取测点，点位图可辅助页面表达 |
| 振动趋势 | 可以构造 | 材料快照 + 演示趋势 + 待补处置后数据 |

| 对中作业卡 | 可以 | P1 作业卡可抽取 |

## 业务待补清单

| 编号 | 待补内容 | 影响 | 没有时怎么办 |
|---|---|---|---|
| Q1 | 确认 P1 不对中作为首版主故障样例 | 决定主线是否锁定 | 默认使用 P1 不对中 |
| Q2 | 确认振动阈值：B 级、停机值 7.1、80% 预警线 5.68 | 决定趋势图和风险等级 | 先按演示口径标注 |
| Q3 | 确认 P1 对中作业卡是否适合作为首版标准作业卡 | 决定处置票卡可信度 | 标注“模板卡，待适配确认” |
| Q4 | 提供处置后复测数据：振动、温度、对中仪结果、垫片调整量 | 决定现场反馈和报告真实感 | 先用演示构造数据 |
| Q5 | 提供 1-2 条真实不对中或类似振动异常历史案例 | 决定知识命中真实感 | 先用历史报告整理 / 演示构造 |
| Q6 | 提供维修报告模板或认可六段式模板 | 决定报告预览格式 | 先用六段式报告 |
| Q7 | 确认知识入库审核角色 | 决定知识复用流程可信度 | 默认诊断专家/设备管理员 |
| Q8 | 指定第二台相似异常设备或认可 P2 演示样例 | 决定复用验证真实感 | 默认使用长岭 P-2 演示样例 |

## 发给业务方的材料补充口径

```text
我们不是要把这些文件直接接进 demo，
而是要从这些文件里抽取字段、指标、阈值、作业卡、报告模板和知识库样例，
再构造成 IMS 数据中台智能运维 demo 模块内可演示的数据闭环。

目前主线可以先按 P1 不对中样例推进。
为了让 demo 更像真实业务，还需要确认阈值、作业卡适配性、处置后复测数据、报告模板和相似案例。
```
