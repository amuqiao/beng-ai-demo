## 2. 两份材料怎么用

### 154站 004P0202 启泵失败报告

这份我已经读出来了，内容很适合做“知识库历史案例”。

它的核心是：

```text
事件：
  154站 004P0202 主输泵启泵失败，手动盘泵也无法盘动

直接原因：
  驱动端机械密封轴套向大气侧窜出约 2mm
  导致机械密封动静环贴合
  进而导致泵轴抱死，无法启泵

排查过程：
  先排查电机是否过载损坏
  拆卸联轴器后远程启动电机，电机正常
  再排查机械密封
  发现机械密封轴套窜出
  复位后可正常盘车

经验总结：
  新投运 / 运行时长短设备也存在隐蔽故障
  需定期维保、每周手动盘泵
  固化启泵前盘泵、排气、检查确认流程
  加强场站人员培训
```

在 demo 里的作用：

```text
知识库相似案例
  -> 支撑“数智员工不是凭空判断”

报告模板样例
  -> 支撑“报告自动生成”

经验复用样例
  -> 支撑“本次经验下次可复用”

作业检查清单
  -> 支撑“启泵前检查 / 盘泵 / 排气”建议
```

### 汨罗站 P-02 非驱动端振动联锁停泵报告

这份文件看起来更适合作为 demo 主线，因为它的题目就是：

```text
非驱动端振动联锁停泵
```

它天然对应当前 demo 主线：

```text
监测异常
  -> 振动联锁
  -> 停泵
  -> 故障诊断
  -> 处置报告
  -> 知识沉淀
```

不过这个 doc 文件目前像是 WPS/图片型文档，文本没有直接抽出来，需要业务方提供可复制文本版，或者我们后续做 OCR/人工摘录。

如果内容能提取出来，我建议：

```text
主线案例：
  用“汨罗站 P-02 非驱动端振动联锁停泵”

知识库相似案例：
  用“154站 004P0202 启泵失败”
```

这样 demo 会更顺：

```text
当前异常：
  汨罗站 P-02 非驱动端振动异常

系统检索知识库：
  命中历史机械密封 / 轴承 / 启泵失败 / 振动异常案例

数智员工输出：
  可能原因
  排查步骤
  风险提示
  作业建议

处置完成：
  生成报告
  沉淀为新案例
  下次相似振动异常可复用
```
