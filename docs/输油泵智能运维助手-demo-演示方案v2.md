# 输油泵智能运维助手 demo 演示方案 v2

> 给业务方确认用：首版 demo 怎么演、诊断模型看什么和输出什么、知识库要落哪些文档和指标。  
> 首版 demo 只做演示闭环，不做真实系统改造。

---

## 1. 业务流程和两条演示路线

首版 demo 只讲同一条主线，分成两段演示：

```text
长岭站 P-1 输油泵机组疑似不对中诊断与处置闭环
```

demo 拆成两层：

| 层级 | 负责什么 | demo 里怎么体现 |
|---|---|---|
| 专业诊断模型 | 判断“是什么问题” | 输出是否异常、异常类型、风险/状态、诊断依据 |
| 设备管理系统 + 知识库 | 判断“怎么处理、怎么闭环” | 命中案例和作业卡，生成处置建议、报告，并入库复用 |

### 路线一：首次异常诊断闭环

```text
设备运行数据
  -> 阈值预警
  -> 专业诊断模型判断：疑似不对中
  -> 专家复核
  -> 设备管理系统和知识库命中对中作业卡 / 历史经验
  -> 生成处置票卡和处置建议
  -> 现场处置反馈
  -> 生成维修报告
  -> 形成新案例入库
```

### 路线二：第二次相似异常复用

```text
第二台设备出现相似异常
  -> 专业诊断模型判断：疑似不对中
  -> 知识库命中第一次沉淀的案例
  -> 推荐相似处置经验
  -> 输出复用说明
```

这两条路线要证明一件事：

```text
第一次能诊断、能处置、能沉淀；
第二次能复用，不是只把报告归档。
```

## 2. 诊断模型输入和输出指标

诊断模型只负责“判断是什么问题”，不负责派工、办票、生成报告。

### 2.1 模型输入指标

| 输入指标 | 业务含义 | P-1 案例样例 |
|---|---|---|
| 设备信息 | 哪台设备发生异常 | 长岭站 P-1 输油泵机组 |
| 测点信息 | 哪些位置出现异常 | 电机、泵、基础等测点 |
| 振动数据 | 异常程度和变化趋势 | 最大振动值 2.62mm/s |
| 状态分级 | 判断设备状态所用标准 | P-1 当前为 B 状态，良等级 |
| 诊断特征 | 支撑故障判断的特征 | 二倍频、相位差、多测点振动 |
| 辅助指标 | 帮助解释异常的其他数据 | 基础振动、温度、压力、流量等 |

### 2.2 模型输出指标

| 输出指标 | demo 展示口径 | P-1 案例建议 |
|---|---|---|
| 是否异常 | 正常 / 异常 | 异常，但不表达为严重故障 |
| 异常类型 | 不对中、松动、轴承异常、工况偏离等 | 疑似不对中 |
| 风险等级 | 正常 / 关注 / 预警 / 严重 | 关注 |
| 评分 / 置信度 | 0-100 或百分比 | 可作为 demo 展示值 |
| 诊断依据 | 支撑判断的关键证据 | 二倍频成分、相位差、多测点振动 |

模型输出到这里为止。下面这些属于设备管理系统 + 知识库：

```text
推荐作业卡
生成处置建议
是否进入处置
生成维修报告
案例入库复用
```

## 3. 知识库落库文档和指标

知识库不是“堆材料”，而是把材料整理成后续能命中的业务知识。

### 3.1 首版需要落库的文档

| 文档类型 | 是否需要 | 需要整理的关键指标 |
|---|---|---|
| 检测报告 / 诊断报告 | 需要 | 设备、异常现象、异常测点、诊断依据、故障类型、建议动作、结论 |
| 对中作业卡 | 需要 | 适用设备、适用故障、作业步骤、角色、工具、安全要求、验收项 |
| 维修报告模板 | 需要 | 报告章节、处置过程、复测结果、结论、审核角色 |
| 历史故障案例 | 建议 | 故障现象、原因判断、处理方式、处理效果、复用标签 |
| 专家经验规则 | 建议 | 触发条件、判断依据、建议先查什么、谁审核 |

### 3.2 P-1 对中作业卡可落库指标

| 作业卡模块 | 可落库指标 |
|---|---|
| 前置条件 | 适用设备、适用故障、是否需要停机/隔离/许可 |
| 角色分工 | 检修负责人、作业人员、运行人员、监护人员 |
| 关键步骤 | 检修前记录、对中测量、调整、复测、恢复备用 |
| 安全要求 | 作业许可、风险分析、安全措施 |
| 验收结果 | 振动复测、试运行、签字关闭作业 |

### 3.3 支撑第二次复用的标签

| 复用标签 | P-1 案例建议 |
|---|---|
| 适用故障类型 | 不对中 |
| 适用症状 | 二倍频成分、相位差、多测点振动、基础振动偏大 |
| 适用设备范围 | 输油泵机组；同类泵/电机对中场景 |
| 前置条件 | 专家复核后进入处置；需要停机、隔离、作业许可和安全风险确认 |
| 推荐作业卡 | 输油泵与电机对中作业卡 |
| 预期效果 | 对中检查或调整后振动回落，设备恢复备用 |
| 复测验收 | 记录处置后振动和轴承温度，试运验收合格后关闭作业 |

## 4. 业务方需要确认

请业务方按三组问题确认：

| 确认组 | 需要确认 |
|---|---|
| 演示路线 | 是否按“长岭站 P-1 输油泵机组疑似不对中”作为主线；是否认可“首次闭环 + 二次复用”两段演示 |
| 模型输入输出 | 输入指标是否完整；输出是否按“是否异常、异常类型、风险等级、评分/置信度、诊断依据”展示 |
| 知识库落库 | 落库文档范围是否认可；对中作业卡是否适配；复用标签是否足够支撑第二次相似异常命中 |

除上述关键项外，趋势曲线补点、第二台相似异常、报告草稿、现场反馈记录等，可按业务口径构造，不阻塞 demo 开发。
