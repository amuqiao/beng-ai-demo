# 07. 页面演示与验收口径

> 本文负责：定义首版 demo 的页面分段、演示节奏和验收标准。  
> 本文不负责：定义字段或素材抽取规则；字段见 [05-结构化数据契约.md](05-结构化数据契约.md)，素材抽取见 [06-素材抽取与待补清单.md](06-素材抽取与待补清单.md)。  
> 关键口径：页面演示读取 IMS 数据中台智能运维 demo 模块内的结构化演示数据，不直接读取业务素材文件。

## 页面分段

| 分段 | 展示效果 | 交互方式 |
|---|---|---|
| IMS 风险看板 | P1 出现异常趋势 / 预警事件 | 点击进入 |
| 一泵一档 / 测点图 | 设备信息、测点结构、关键测点高亮 | 点击测点 |
| 趋势与阈值 | IMS 监测快照、演示趋势、预警线、处置后回落 | 预设结果 |
| 频谱与相位 | 1X / 2X / 6X、相位差证据 | 预设结果 |
| 诊断结果卡 | 疑似不对中、关注级、证据标签、建议动作 | 专家确认 |
| 知识命中卡 | 作业卡、专家规则、历史案例、报告模板 | 展示命中理由 |
| IMS 处置票卡 | 角色、许可/JSA 字段、工具、步骤 | 点击生成 |
| 现场反馈 | 调整记录、复测结果、验收结论 | 填写 / 确认 |
| 报告草稿 | 事件、证据、处置、复测、经验总结 | 点击确认 |
| 知识入库 | P1 处置案例入库 | 点击审核 |
| 复用验证 | 第二台相似异常命中 P1 案例 | 展示复用理由 |

## 推荐演示节奏

| 时间 | 内容 | 讲解重点 |
|---|---|---|
| 0:00-1:00 | IMS 风险看板进入 P1 异常事件 | 系统从数据中台看到异常趋势 |
| 1:00-3:00 | 一泵一档、测点、趋势、阈值 | 离散数据被组织成可诊断事件 |
| 3:00-5:00 | 频谱、相位、诊断结果 | 诊断不是黑盒，有证据标签 |
| 5:00-6:30 | 专家复核、知识命中 | 知识库提供依据和处置入口 |
| 6:30-8:30 | 处置票卡、现场反馈 | 诊断推动标准化处置 |
| 8:30-10:00 | 报告草稿、案例入库 | 过程资料沉淀为知识 |
| 10:00-12:00 | 第二台相似异常复用验证 | 知识下次能被复用 |

## 演示主叙事

```text
过去：
振动、温度、压力、流量、频谱等数据分散，
异常判断依赖有经验的人反复看数据、找资料、写报告。

demo 要证明：
IMS 数据中台上的智能运维 demo 模块可以把设备、测点、监测数据、维护记录组织起来；
诊断模型把离散数据转成疑似故障和证据标签；
知识库把诊断结果转成可执行的作业卡、专家规则和报告模板；
现场处置结果又沉淀为案例，下次相似异常可复用。
```

## 验收口径

| 验收项 | 标准 |
|---|---|
| 主线清晰 | 能从 IMS 异常事件讲到复用验证 |
| 素材定位正确 | 不把 P1 报告说成 demo 运行时输入 |
| 数据规整 | 本 demo 模块消费 IMS 数据中台内结构化演示数据 |
| 模型边界清楚 | 不宣称真实模型训练或真实 AI API |
| 证据可解释 | 趋势、阈值、频谱、相位能支撑疑似不对中 |
| 人工边界清楚 | 诊断、处置、报告、入库都有人工确认 |
| 知识复用成立 | 第二台相似异常能命中 P1 新案例 |
| 生产边界清楚 | 不宣称真实 HSE/供应链打通或真实生产流程改造 |

## 不应对外宣称

```text
不要说 demo 现场会导入 P1 检测报告。
不要说模型直接读取 Word / Excel / 图片。
不要说已经接入真实在线监测系统。
不要说已经训练出真实诊断模型。
不要说已经接入真实大模型 API 或真实 RAG 引擎。
不要说已经打通 HSE、供应链或改造生产流程。
不要说系统可以自动替代专家判断和报告审核。
```

可以对外说：

```text
首版 demo 基于业务素材抽取了结构化样例数据，
在 IMS 数据中台上的智能运维 demo 模块内打通了预警、诊断、复核、处置、报告、知识入库和复用验证闭环。
真实实时接口、真实模型训练和 HSE/供应链等系统集成不属于首版 demo 承诺。
```
