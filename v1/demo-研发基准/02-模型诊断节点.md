# 02. 模型诊断节点

> 本文负责：定义诊断模型在 demo 中的输入、输出、证据解释和边界。  
> 本文不负责：真实模型训练、真实算法选型或真实接口接入。  
> 关键口径：模型输入是结构化数据，不是 P1 检测报告文件。

## 模型节点定位

诊断模型节点只做一件事：

```text
读取 IMS 数据中台智能运维 demo 模块中的设备、测点、时序、阈值、频谱、相位
  -> 输出可解释的诊断结果
```

首版可以用“预置诊断结果 + 可解释趋势 / 频谱 / 相位证据”表达专业模型能力，不需要接入真实 AI API 或训练真实模型。

## 首版诊断目标

首版故障类型：

```text
疑似不对中
```

它是 demo 的主故障，不代表正式项目只支持不对中。后续可扩展：

| 故障类型 | 首版处理 | 需要补充 |
|---|---|---|
| 不对中 | 做完整闭环 | 阈值口径、处置后复测数据、专家确认 |
| 轴承磨损 | 后续扩展 | 轴承故障样例、频谱特征、处置作业卡 |
| 不平衡 | 后续扩展 | 不平衡样例、诊断规则、处置模板 |
| 大修周期预测 | 后续扩展 | 泵效测试、运行状态标准、预测规则 |

## 模型输入

| 输入类别 | 运行时字段示例 | 用途 | 样例依据 |
|---|---|---|---|
| 设备上下文 | 站场、设备 ID、泵型号、电机型号、转速、转频 | 确定诊断对象和频谱倍频 | P1 报告、IMS 单元模型 |
| 测点结构 | 测点 ID、部位、方向、组件 | 把数据落到具体部位 | P1 报告、仪表点位图 |
| 时序数据 | 时间、振动、温度、压力、流量 | 展示趋势和阈值越限 | P1 报告抽取 + 演示构造 |
| 阈值规则 | B 级阈值、停机值、80% 预警线 | 形成预警事件和风险等级 | 业务补充口径，待确认 |
| 频谱特征 | 1X、2X、6X、峰值标签 | 支撑疑似不对中 | P1 报告抽取 |
| 相位特征 | 测点组合、相位差、相关性 | 支撑不对中解释 | P1 报告抽取 |
| 历史上下文 | 历史案例、维护记录、同类设备标签 | 辅助知识命中 | 历史报告和演示构造 |

## 模型输出

首版模型核心输出保持简单，避免把业务流程字段或页面派生字段塞进模型：

| 输出 | 示例值 | 说明 |
|---|---|---|
| 故障类型 | `misalignment_suspected` | 疑似不对中 |
| 风险等级 | `attention` | 关注级，不宣称自动停机 |
| 证据标签 | `2X频谱`、`相位差异常`、`基础振动偏大` | 用于解释和知识命中 |
| 建议动作 | `检查对中`、`检查地脚螺栓`、`检查管道固定`、`检查工况点` | 用于匹配作业卡和专家规则 |

`是否异常` 可以作为页面判断用的布尔包装，但不是核心诊断结论。`状态等级 B` 属于阈值 / 页面展示派生字段，归属异常预警事件或页面展示层，不作为模型核心出参。

## 页面解释方式

页面不展示“模型内部算法”，只展示模型输入到输出的可解释证据链：

```text
异常趋势：振动值进入关注区
频谱证据：2X 成分突出
相位证据：相位差接近不对中特征
综合结论：疑似不对中
建议动作：择机检查对中，辅助检查基础、管道固定、工况点
人工边界：专家确认后才进入处置票卡
```

## 模型不负责

```text
不直接读取 Word / Excel / 图片素材
不自动生成工单
不派维修人员
不办理 HSE 票证
不调用供应链
不生成报告正文
不自动写入知识库
不替代专家最终确认
```

这些动作由 [04-IMS处置与报告闭环.md](04-IMS处置与报告闭环.md) 和 [03-知识库与复用闭环.md](03-知识库与复用闭环.md) 承接。
