# demo 研发基准文档集

> 本目录是输油泵智能运维助手首版 demo 的研发基准。核心纠偏：业务素材不是 demo 运行时输入，而是用于抽取结构化字段、指标、阈值、样例数据和知识库内容的依据。

## 心智模型

正确的数据关系是：

```text
业务素材（notes / P1 / pic）
  -> 抽取设备、测点、阈值、趋势、频谱、相位、作业卡、报告模板、知识条目
  -> 构造 IMS 数据中台智能运维 demo 模块所需的结构化演示数据和知识库样例
  -> demo 运行时只读取模块内的结构化演示数据
```

正确的业务运行链路是：

```text
IMS 数据中台上的智能运维 demo 模块
  -> 形成异常趋势或预警事件
  -> 诊断模型读取结构化时序、频谱、相位、阈值、设备测点数据
  -> 输出疑似故障、风险等级、证据标签、建议动作
  -> 知识库命中作业卡、专家规则、历史案例、报告模板
  -> 在 IMS 模块内完成复核、处置票卡、现场反馈、报告、案例入库
  -> 下一次相似异常复用已沉淀案例
```

首版主线是：**IMS 数据中台智能运维 demo 模块中的长岭站 P-1 输油泵机组疑似不对中预警处置闭环**。P1 检测报告和对中作业卡只用于抽取这条主线所需的样例数据，不作为 demo 流程里的“导入文件”。

## 首版边界

首版要做：

```text
IMS 数据中台智能运维模块内的结构化演示数据驱动业务闭环
可解释诊断模型输出
知识库命中和处置依据展示
人工复核和标准处置票卡
现场反馈、报告生成、案例入库
第二台相似异常复用验证
```

首版不做：

```text
真实实时接口接入
真实模型训练
真实 AI API / 真实 RAG 引擎
真实 HSE / 供应链联动
真实生产流程改造
系统自动替代专家确认
```
